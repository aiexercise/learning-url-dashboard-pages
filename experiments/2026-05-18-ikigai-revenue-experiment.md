# 상현님 이키가이 수익화 실험 v0.1

생성: 2026-05-18 20:11 KST
상태: 만들기 전에 팔기 / 시장검증 단계

## 0. 목표

목표는 앱/서비스를 먼저 만드는 것이 아니라, **첫 1원**이 들어오는지를 확인하는 것이다.

검증 기준:
- 1차 성공: 10명에게 제안 → 3명 이상 관심/상담 응답
- 2차 성공: 1명 이상 유료 결제 또는 예약금 입금
- 실패 기준: 10명 제안 후 유료 의향 0명 → 오퍼/타깃을 바꿔 1단계로 회귀

## 1. 이키가이 4요소 교집합

### 좋아하는 것
- AI, 기록, Obsidian/Hermes, 자동화, 자기이해, 자료 요약, 판단 구조화

### 잘하는 것
- 흩어진 경험/정보를 구조화해서 판단 기준과 실행 단위로 바꾸기
- AI에게 일을 맡기는 구조 설계
- 반복 판단을 줄이는 개인 시스템 구축

### 세상이 필요로 하는 것
- AI는 쓰고 싶지만 뭘 시켜야 할지 모르는 사람
- 자료/링크/메모는 많은데 실제 행동으로 연결하지 못하는 사람
- 반복 업무/정보정리/보고서 때문에 시간을 쓰는 1인 사업자·직장인·리더

### 돈이 될 수 있는 것
- 개인 맞춤 AI 비서/학습·판단 시스템 구축
- Obsidian/Notion/Google Drive/Telegram 기반 자동 요약·보고·리마인드 시스템
- 업무자료 → 실행 브리핑 → 자동화 워크플로 설계

## 2. 첫 유료 오퍼

### 오퍼명
**AI 개인 운영체제 1일 진단 + 자동화 설계**

### 한 문장 설명
흩어진 메모, 링크, 업무자료, 반복 보고를 AI가 매일 정리하고 실행 브리핑으로 보내주는 개인 맞춤 시스템을 설계해드립니다.

### 타깃
처음에는 넓게 잡지 않고 아래 중 1개만 선택한다.

1. 자료와 메모가 많은 직장인/리더
2. 블로그·뉴스·유튜브를 많이 보는 투자/리서치 관심자
3. Notion/Obsidian/Google Drive를 쓰지만 정리가 안 되는 사람
4. 반복 보고서/요약/리마인드 업무가 있는 1인 사업자

### 초기 권장 타깃
**자료·링크·메모가 많지만 실행으로 연결하지 못하는 직장인/리더**

상현님 강점과 가장 잘 맞고, 현재 만든 학습 대시보드/Hermes 시스템을 실제 사례로 보여줄 수 있다.

## 3. 가격 가설

시장가격은 플랫폼/강사/구현 범위에 따라 크지만, 첫 검증은 아래 3단계로 진행한다.

### 1단계: 진단형
- 가격: 5만 원
- 구성: 30분 상담 + 현재 정보흐름 진단 + 자동화 후보 3개 제안
- 목적: 진짜 돈 낼 사람이 있는지 확인

### 2단계: 설계형
- 가격: 15만 원
- 구성: 60분 인터뷰 + 개인 AI 운영체제 설계도 + 프롬프트/폴더/자동화 구조 제안
- 목적: MVP 전 수요 확인

### 3단계: 구현형
- 가격: 30만~50만 원
- 구성: Telegram/Google Drive/Obsidian/Notion 중 1개 흐름을 실제 작동하게 구현
- 목적: 첫 고객 사례 확보

초기 제안 가격은 **15만 원**이 적절하다. 단, 첫 고객에게는 "파일럿 5만 원"으로 진입해도 된다.

## 4. 만들기 전에 팔기: 검증 메시지

### 지인/동료용 짧은 메시지

요즘 제가 AI로 개인 업무/자료 정리 시스템을 만들고 있는데, 작은 유료 실험을 해보려고 합니다.

대상은 메모, 링크, 업무자료, 보고서가 많아서 정리는 해야 하는데 실행으로 잘 안 이어지는 사람입니다.

30~60분 정도 현재 자료 흐름을 들어보고,
“AI가 매일 요약/분류/브리핑해주는 개인 운영체제”를 어떻게 만들 수 있을지 설계해드리는 방식입니다.

파일럿이라 5만 원으로 3명만 받아보려고 하는데, 혹시 본인이나 주변에 필요할 만한 사람이 있을까요?

### 더 직접적인 판매 메시지

혹시 요즘 자료/메모/링크/보고서가 쌓이는데 정리와 실행이 잘 안 되는 문제가 있으신가요?

제가 AI를 이용해서 개인 맞춤으로
- 들어오는 자료 자동 요약
- 중요도/실행 여부 분류
- 매일 Telegram/카톡식 브리핑
- 반복 보고서 초안 생성
같은 흐름을 설계하는 파일럿을 해보고 있습니다.

정식 서비스 전 시장검증이라 3명만 5만 원에 진행하려고 합니다.
원래는 15만 원 정도로 생각하는 구성이고, 30~60분 인터뷰 후 바로 쓸 수 있는 개인 AI 업무흐름 설계안을 드립니다.

관심 있으시면 제가 질문 5개만 보내드릴게요.

## 5. 랜딩 초안

### 제목
AI가 내 자료를 매일 정리하고, 오늘 할 일로 바꿔준다면?

### 부제
흩어진 메모, 링크, 업무자료, 보고서를 AI 개인 운영체제로 바꿔드립니다.

### 문제
- 좋은 자료는 많이 보는데 실제 적용이 안 된다
- Notion/Obsidian/Drive에 쌓이기만 한다
- 매번 비슷한 보고서와 요약을 반복한다
- AI를 쓰고 싶지만 내 업무에 어떻게 붙일지 모르겠다

### 제공 결과물
- 현재 정보흐름 진단
- 자동화 가능한 업무 3개 선정
- 개인 맞춤 AI 운영체제 설계도
- 바로 복사해 쓸 수 있는 프롬프트/폴더 구조/자동화 흐름
- 원하면 1개 흐름은 실제 구현까지 연결

### 가격
파일럿 3명: 5만 원
정가 예정: 15만 원
구현형: 별도 견적 30만~50만 원부터

### CTA
관심 있으면 “AI 운영체제 파일럿 신청”이라고 메시지를 보내주세요.

## 10. 판정 기준

### 계속 진행
- 10명 중 3명 이상 관심
- 1명 이상 5만 원 결제/예약금 가능
- 문제 설명이 구체적임

### 수정 후 재검증
- 관심은 있지만 돈을 안 냄
- “좋긴 한데 지금은 필요 없다”가 많음
- 타깃이 너무 넓음

### 1단계로 회귀
- 10명 중 관심 0~1명
- 불편은 있지만 돈 낼 정도는 아님
- 상현님이 해도 가슴이 뛰지 않음
